# Video Producer: reference prototype next to the plugin

Each composite puts the reference interface prototype on the left and the plugin running inside PotionUI on the right. Both sides are 1440 x 900 captures of the interface in the default project state (no selection unless the line says so), reduced to 50 % and joined into one 1440 x 450 JPEG (quality 80). The prototype side shows its own sample project ("Alpine escape"); the plugin side shows the starter project "Dawn at the harbour" that the plugin opens on (see Starter project below), created by the page on the real server, with the engine set to Wan 2.1 / 2.2. The plugin no longer ships a demonstration project with simulated takes, so the content of the two halves differs by design: the lines below describe the differences of the interface, not of the content. Every screen exists in a dark and a light version: `<screen>-dark.webp` and `<screen>-light.webp`. The `about-*` and `tour-*` images are the exception: they show the plugin alone (720 x 450, JPEG quality 90), see their rows below.

Full-size captures (1440 x 900 and 1280 x 720, plus a second series of the plugin) are not kept in the repository. The JPEG composites were captured with an interface language other than English, so this page gives the English names of the labels they show. The plugin halves were retaken at step 7, after the accessibility work: 24 px pointer targets on the timeline (block handles, fade handles, camera keys in their own band above the 3D plan, 24 x 24 marker pins), lighter window subtitles, focus rings on switches and on the first control of a window. The plugin halves of `about-*`, `shortcuts-*` and `tour-*` were retaken on 18 October 2026, after the shortcut and FCPXML changes, on an instance that had the Wan 2.1 / 2.2 preset but none of its model files: behind the blurred window, the Production bar reads "Models to install for this preset" instead of the estimate.

In this repository every image is stored as WebP (quality 85), converted from the JPEG and PNG files that this page describes: sizes and crops are unchanged, and the formats and qualities given below are those of the captures.

## Differences that apply to every composite

- The plugin page sits next to the 56 px PotionUI icon rail and the host page header is hidden. At 1440 px the plugin area is 1376 px wide (rail plus an 8 px scrollbar gutter reserved by the host), so columns are about 20 px narrower: storyboard thumbnails are 12 px shorter, and the layouts that wrap earlier are kept on one line.
- Status bar: a language button replaces the prototype label, and the active tool reads "Select tool (A)" instead of "Tool: Select (A)". The page saves the starter project on the server as soon as it opens, so the project bar reads "Saved at" and the time of that save.
- Shortcut hints follow the platform (`Ctrl+G` instead of `⌘ G`) and decimals follow the locale (`6,0 s` instead of `6.0 s`).
- Hand-made controls are replaced by host components (Button, IconButton, Tooltip, Badge, SegmentedControl, Alert, Switch): labels are weight 500 instead of 400, secondary fills are one step lighter (`surface-3` instead of `surface-2`), badges are 22 px tall with wider padding where the prototype chips are 20 px, and settings toggles are 44 x 24 px switches instead of checkboxes.
- The engine selector lists the presets of the instance ("Wan 2.1 / 2.2"), grouped by the backend names given by the host, instead of "ComfyUI · RTX 4090".
- Vocabulary is unified: one name for the prompt of a shot ("Shot prompt"), one for the reference video type ("Control video") and "Subtitles"; the prototype used several wordings for each.
- Chips drawn over images (shot numbers, durations, scope tags, take letters) use a dark scrim with white text in both themes, as in the prototype. Status labels on the take thumbnails (draft, final, to redo) are white instead of tinted.
- The prototype has a "3D scene" workspace. The plugin has none since 25 October 2026: it has five workspaces and no 3D tool. The images taken before that date, composites and PNG crops alike, still show the "3D scene" tab in the workspace bar when the bar is in the picture.
- Since 26 October 2026 the workspace bar reads Media, Storyboard, Director AI, Mix, Play, and Director AI has no dock with tabs: a summary on the left (one line per view, the engine and "To check"), one view at a time in the center (Review, Direction, Bible, References), the composed prompt or the chosen card of the Bible in place of the Inspector for two of them, and no timeline. The generation queue opens under the list button of the Production bar, which shows only in Storyboard and Director AI, and no Generate button is left outside that bar and the Synopsis and breakdown window. Every image below was taken before that date: where the workspace bar is in the picture, it shows the earlier order and name of the workspaces; where Director AI is, it shows the dock with its tabs ("Direction", "References", "Results", "Queue") above the timeline; and the Production bar shows in every workspace but Play.
